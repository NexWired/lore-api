Remilia Red
 is a standardized corporate color specification used by 
Remilia Corporation
 in digital design and branding, defined by the hexadecimal color code #FF0000 (RGB: 255, 0, 0).

[
1
]

 The color represents maximum red saturation in the RGB color space.

Remilia Red was developed as a companion specification to 
Remilia Blue
, providing an alternative primary color for the corporation's visual identity system. The color maintains the same approach of using pure, maximum-saturation RGB values, ensuring consistency within the corporate color palette.

Technical specifications

Remilia Red is defined by the following color values:

Hexadecimal
: #FF0000

RGB
: 255, 0, 0

Color space
: sRGB

Saturation
: 100%

Brightness
: 100%

The specification uses maximum red channel intensity while setting green and blue channels to zero, producing a pure primary red in digital displays.

Usage

The color is used across 
Remilia Corporation
's digital applications, often in combination with 
Remilia Blue
 (#0000FF), 
XCELA Green
 (#00FF00), RGB Black (#000000), and RGB White (#FFFFFF) to create high-contrast colorways for web design, merchandise, and promotional materials.

[
2
]

 This approach exploits pure digital colorways difficult to recreate in print and physical material.
