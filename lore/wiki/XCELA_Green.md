XCELA Green
 is a standardized corporate color used by the 
XCELA Group
 in digital design and branding, defined by the hexadecimal color code #00FF00 (RGB: 0, 255, 0).

[
1
]

 The color represents maximum green saturation in the RGB color space, with no red or blue components.

XCELA Green was developed as the primary color specification for the XCELA Group, a short-lived sister collective to 
Remilia Corporation
 founded by 
Charlotte Fang
 and focused on research and experimentation in what they termed "new computing."

[
2
]

Like 
Remilia Blue
 and 
Remilia Red
, XCELA Green follows the approach of using pure, maximum-saturation RGB values to create a distinctive digital color identity. The color is occasionally used in 
Remilia Corporation
's broader visual identity system alongside its other primary colors.

Technical specifications

XCELA Green is defined by the following color values:

Hexadecimal
: #00FF00

RGB
: 0, 255, 0

Color space
: sRGB

Saturation
: 100%

Brightness
: 100%

The specification uses maximum green channel intensity while setting red and blue channels to zero, producing a pure primary green in digital displays.

Usage

The color occassionally appears in combination with 
Remilia Blue
 (#0000FF), 
Remilia Red
 (#FF0000), RGB Black (#000000), and RGB White (#FFFFFF) to create high-contrast colorways that exploit pure digital color values difficult to reproduce accurately in print and physical materials.
