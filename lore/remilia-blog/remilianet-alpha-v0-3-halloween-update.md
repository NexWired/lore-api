RemiliaNET Alpha v0.3: Halloween Update

        

        

            
Oct 23, 2025

            
        

        

            

                
This Halloween we welcome you to the first of many holiday themed updates to RemiliaNET. Please enjoy several spooktacular new additions to our activities, features, and functions of the site along with plenty of back end improvements.

Halloween Theme

The entire website has been outfitted with a special festive Halloween theme to fit the season. Enjoy the subtle autumnal motifs paired with a revamp of our sound system to fit a "skeletonic" scale for ideal creepy but playful ambiance. Send a friend request and see what happens!

Hyper-realtime Global Chat

The long-awaited hyperrealtime global chat is now available for users to interact verbally with one another. To the mirth or dismay of various RemiliaNETizens, the infancy of innocent silence will not be completely discarded from user experience. All users must reach Level 10 in the BeetleBoy module before they are allowed to access the chat. This ensures a time-investment gatekeeping mechanism for the chat, filtering out low effort spam.
Miladychan Integration

Chat Features

Currently, global chat shares the same real-time experience, image sharing, and emoji reaction functions as Miladychan. Usernames are colored in chat based on their profile theme and can be clicked on to discover new friends. You can expect chat to expand to multi-channel groupchats and DM's featuring the same hyper-realtime functionality following an overhaul.

Miladychan Integration

Global chat is built on the same Miladychan infrastructure which powers our favorite real-time image board, also featured as the CULT.inc front page chatroom. With this update we are now integrating RemiliaNET's SSO with Miladychan, allowing users to sign into Miladychan using their RemiliaNET profile. Users will still be able to post anonymously, or with their username and profile picture thumbnail.

BeetleBoy Updates

Two new beetles and their respective beetlegirls have been added for the Halloween update. One of these is quite rare. These beetlegirls are seasonally themed and will only be available to catch for the next two weeks during the Halloween season. These seasonal beetles will only be available to hunt during the related holiday.

Beetleboy Patch Notes:

Inventory now scrollable when your Beetles exceed the amount of slots originally provided

Pity timer has been adjusted to lower green/no beetle streaks

Cheese streak rate has been slightly tweaked for improved cheese claim volume over time

Rarity distribution has been balanced across Beetle tiers (tier reveal soon!)

Cheese claim timer synchronized globally across players

Loading speeds should be faster now due to performance tweaking and bloat reduction

Bug Report System

Users now have the ability to report bugs they encounter on RemiliaNET and also provide suggestions for features in a new menu, located in a tab on the bottom right part of the website. You will be able to poke the devs as well through this menu, ensuring their compliance via a forked remote behavior collar incentive system which makes them type faster and code better.

We highly encourage you to utilize the bug report form for any or all issues you encounter in the future, along with providing suggestions for what you'd like to see on the site next. Your contributions to RemiliaNET Alpha will not go unnoticed.
